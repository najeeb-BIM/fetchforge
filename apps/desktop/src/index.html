Add the FetchForge extension to your browser

Chrome cannot install the extension by itself — it takes about a minute by hand, once:

  1. Open Chrome (or Edge, or Brave) and type chrome://extensions in the address bar, then press Enter.
  2. Turn on Developer mode — the switch at the top right of that page.
  3. Click Load unpacked (top left).
  4. In the folder window, click the address bar at the top, paste %USERPROFILE%\ff-extension, press Enter, then click Select Folder.
  5. FetchForge appears in the extensions list. Click the puzzle-piece icon in the toolbar and pin FetchForge so its button is always visible.
  6. Then pair it: click Pair browser in this app and enter the code in the extension popup.

If the ff-extension folder is missing, the extension files were not copied during install — ask for them to be copied to that folder first.

Settings

When this is on, FetchForge shuts the computer down 60 seconds after the last download completes. You can stop it in that minute with shutdown /a. It never fires while a download is queued, downloading, or paused.
