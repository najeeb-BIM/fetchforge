1. Go to github.com and create a free account, keeping your password private and never sharing it with anyone, including me.
2. Click New repository, name it fetchforge, leave it Private, and click Create repository.
3. On your computer, unzip the FetchForge project zip so you can see its files and folders.
4. On the new repository page, click Add file, then Upload files, and drag in all the unzipped files and folders (not the zip itself). Do not upload the target folder, backups, or any token or key file.
5. Scroll down and click Commit changes, then wait for the files to appear in the repository.
6. Click the Actions tab at the top of the repository page.
7. In the left list, click Windows build, then click the Run workflow button on the right.
8. Click the green Run workflow button in the small pop-up to start the build.
9. Wait for the build to finish with a green tick; this can take a while, so do not close the page early.
10. Click the finished run, scroll to Artifacts, download fetchforge-windows-x64, unzip it, and run the installer inside.
